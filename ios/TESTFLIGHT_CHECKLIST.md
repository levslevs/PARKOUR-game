# TestFlight check — Parkour Enemies 1.0.0 (1)

Install Parkour Enemies from the internal TestFlight invitation on both an iPhone and an iPad. Use the Apple ID that received the invitation. This is an internal beta; the app has not been submitted to public App Review.

For each device, record the model and iOS/iPadOS version, then check:

1. **Menu and shop:** open Character shop and return to the menu. Character images and buttons should appear and respond.
2. **Controls:** start a run, hold left/right and jump together. Try short and long jumps. Buttons should never stay pressed after releasing a finger.
3. **Screen layout:** on iPhone check both landscape directions; on iPad check portrait and landscape. Controls and dialogs should remain visible and usable.
4. **Pause:** pause and resume manually, then switch to another app and return. The game should be paused on return.
5. **Saved progress:** earn at least 6 coins, unlock Doughnut, close the app completely and reopen it. The character and remaining coins should still be saved.
6. **Offline and sound:** reopen the game without an internet connection. Check sound enabled/disabled, the device volume and silent setting. Support links require internet.
7. **Courses:** try all five rounds, including falling, losing a life, retrying and reaching a portal. Report any place where progression seems impossible.

Send the device model, OS version, exact steps and expected/actual behavior for each problem. A screenshot or screen recording helps. Avoid including private information in screenshots or public GitHub issues.

After both device checks, explicitly confirm whether the build is ready for App Review or list the issues that need fixing. No submission will happen before that confirmation.
